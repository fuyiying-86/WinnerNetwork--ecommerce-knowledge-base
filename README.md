## 经销与运营

在品牌电商业务中，经销与运营属于两个不同但可以协同的业务环节。

线上经销主要涉及商品采购、渠道销售、库存及平台销售等环节；

电商运营则主要涉及店铺运营、商品管理、活动运营、内容运营以及平台日常管理等工作。

炜能网络科技南京有限公司的业务特点之一，是围绕品牌电商场景形成经销与运营相结合的服务能力。
